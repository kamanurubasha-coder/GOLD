# AR JEWELLERY 💎👑
### Luxury Gold & Diamond E-Commerce Shopping Application & Store Owner Portal

A modern, responsive e-commerce web platform for **AR JEWELLERY**, featuring real-time live gold and silver market bullion rates, 22K 916 BIS hallmarking standards, interactive gold price estimation calculator, shopping bag, wishlist, saved addresses, order tracking, real-time admin order notifications, and direct WhatsApp customer desk.

---

## 🌟 Key Features

### 1. Luxury White & Royal Gold Aesthetic
- Pristine ivory & white background (`#FAF8F5`, `#FFFFFF`) with rich champagne gold gradients (`#D4AF37`, `#B8860B`).
- Smooth 60fps animations:
  - **Golden Gleam Reflection (`.gold-gleam`)** across buttons
  - **Breathing Floating Showcase (`.hero-float`)**
  - **Ambient Radial Aura Glow (`.gold-aura-glow`)**
  - **Logo Halo Pulse (`.logo-glow-ring`)**
  - **Elastic Cart & Wishlist Badge Pop (`.badge-pop`)**
  - **Intersection Observer Scroll Reveals (`.fade-up-init`)**
  - **Celebration Confetti Shower (`launchGoldenConfetti`)**

### 2. User Authentication & Profile Hub
- **Customer Registration & Login**: Full name, mobile, email, password with validation.
- **5 Working Profile Modals**:
  1. `⚙️ My Preferences`: Karat preferences, ring/bangle sizes, rate drop alerts.
  2. `📦 My Orders`: Order timeline tracking (`Confirmed` ⟶ `BIS Hallmark Verified` ⟶ `Insured Transit` ⟶ `Delivered`).
  3. `📍 Manage Address`: Multi-address manager with default selection auto-populated at checkout.
  4. `❤️ My Saved Wishlist`: Save favorite jewellery and transfer directly to bag.
  5. `🚪 Logout`: Secure session termination.

### 3. Transparent Live Gold & Silver Pricing
- Real-time bullion market ticker for 24K pure gold, 22K 916 hallmark gold, 18K diamond gold, and pure 999 silver.
- **Interactive Price Calculator**: Computes exact price from net weight, karat purity, making charges, and 3% GST with one-click WhatsApp quotation generation.

### 4. Hidden Store Owner / Admin Dashboard
- Discrete store owner access (`ARGold` / `AR@123` or `AsmaGold` / `Asma@123`).
- **Real-Time Purchase Notification**: Golden audio chime alert and unread notification counter whenever any customer purchases a jewel.
- **Live Bullion Rate Controller**: Update 22K, 24K, 18K, and Silver prices store-wide.
- **Product Publisher**: Add custom jewellery ornaments dynamically to the catalog.
- **Monthly Revenue & Order Analytics**: Live tracking of orders and billing metrics.

### 5. Seamless WhatsApp Customer Desk
- Floating WhatsApp button with concentric ripple animations.
- Dispatches formatted customer inquiries directly to the store management.

## 🚀 Deployment Instructions (GitHub Pages)

1. Create a repository on GitHub named `ar-jewellery`.
2. Push all files to the `main` branch.
3. In repository **Settings** ➔ **Pages**:
   - Source: **Deploy from a branch**
   - Branch: **`main`** / Folder: **`/ (root)`**
4. Your live website will be available at:
   `https://<your-github-username>.github.io/ar-jewellery/`
